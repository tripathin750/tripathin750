### 🛡️ Featured: AI Threat Intelligence Assistant

An evidence-grounded CVE threat-intelligence platform — not a demo, a running production service.

- Ingests live data from **NVD**, **CISA KEV**, and **FIRST.org EPSS** — the same three-signal fusion (confirmed exploitation + severity + predicted exploitation probability) that commercial Risk-Based Vulnerability Management platforms sell as their core product.
- **Google Gemini** integration for evidence-grounded analysis and MITRE ATT&CK inference, with a deterministic rule-based fallback so the service never goes down when the LLM does.
- **Bulk Triage**: paste up to 50 CVE IDs, get a ranked, ticket-ready worklist — built for how SOC analysts actually work.
- 86 automated tests, fully offline. Full architecture docs — data-flow, sequence, and ER diagrams — published live.
